# Lao Web Studio V3.0 Stable

Clean rebuild. No V2.x JavaScript or SQL is used.

## Install
1. Edit `supabase-config.js` with your Supabase Project URL and anon key.
2. Upload all files to GitHub.
3. Run `SUPABASE-V3.0-COMPLETE-SETUP.sql` once.
4. Open `system-check.html`.
5. Test the quotation form.

Expected health result: version `3.0.0`.
